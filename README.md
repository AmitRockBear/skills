## Skills

| Skill | What it does |
| --- | --- |
| [babysit-pr](skills/babysit-pr/SKILL.md) | Monitors CI and reviews, checks findings, and fixes issues. |
| [boundary-discipline](skills/boundary-discipline/SKILL.md) | Keeps validation at system boundaries. |
| [council](skills/council/SKILL.md) | Compares independent reviews from different model families. |
| [create-pr](skills/create-pr/SKILL.md) | Opens PRs with clear descriptions and verification evidence. |
| [explainer-video](skills/explainer-video/SKILL.md) | Creates animated videos with narration. |
| [grilling](skills/grilling/SKILL.md) | Resolves design decisions through focused questions. |
| [html-communication](skills/html-communication/SKILL.md) | Writes HTML reports, plans, comparisons, and mocks. |
| [measure-change](skills/measure-change/SKILL.md) | Measures changes against a baseline. |
| [pr-clean-code-review](skills/pr-clean-code-review/SKILL.md) | Reviews complexity, duplication, and code contracts. |
| [pr-spec-review](skills/pr-spec-review/SKILL.md) | Checks PRs against requirements. |
| [pr-walkthrough](skills/pr-walkthrough/SKILL.md) | Explains PRs with concrete before-and-after examples. |
| [resume-work](skills/resume-work/SKILL.md) | Recovers context for interrupted tasks. |
| [review-loop](skills/review-loop/SKILL.md) | Runs spec and code reviews, fixes, and PR monitoring. |
| [type-system-discipline](skills/type-system-discipline/SKILL.md) | Models valid states with types. |
| [typescript-best-practices](skills/typescript-best-practices/SKILL.md) | Guides TypeScript inference, validation, and type design. |
| [use-claude](skills/use-claude/SKILL.md) | Runs resumable tasks through Claude CLI. |
| [use-codex](skills/use-codex/SKILL.md) | Runs tasks through Codex CLI and preserves context. |
| [use-cursor](skills/use-cursor/SKILL.md) | Runs resumable tasks through Cursor CLI. |
| [verify-change](skills/verify-change/SKILL.md) | Checks running behavior and records evidence. |
| [write-skill](skills/write-skill/SKILL.md) | Turns workflows into reusable skills. |
